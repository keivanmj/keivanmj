## 🚀 Featured Projects

### 📈 Market Data Analysis & Forecasting

A large-scale market intelligence and forecasting platform built around
real-time data collection, data engineering, and machine learning.

**Highlights**
- Real-time data collection using APIs, GraphQL, and Selenium
- PostgreSQL data pipelines operating on a 300+ GB database
- Feature engineering and time-series feature stores
- Historical backfills, rollups, and data-integrity validation
- Workflow orchestration with Apache Airflow and Linux services
- Monitoring and visualization with Grafana
- Temporal Fusion Transformer (TFT) forecasting pipeline
- Forecasting market prices, volume, and behavior

**Tech:** Python · PostgreSQL · PyTorch · Airflow · Grafana · Linux · Selenium
