# Featured Projects

## Market Data Analysis & Forecasting

A large-scale market intelligence and forecasting platform designed to collect,
process, validate, and model continuously changing market data.

### Highlights

- Real-time data ingestion using **REST APIs, GraphQL, and Selenium**
- PostgreSQL-based data infrastructure operating on a **300+ GB database**
- Time-series feature engineering and ML feature stores
- Historical data reconstruction and backfill pipelines
- FIFO processing and data-integrity validation
- Automated rollups and retention systems
- Workflow orchestration using Apache Airflow
- Linux services for continuously running data-processing pipelines
- Grafana-based database monitoring and visualization
- Temporal Fusion Transformer forecasting pipeline
- Market price, volume, and behavior forecasting
